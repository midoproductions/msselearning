## 🚀 How to Use

The chatbot works immediately - no configuration needed! It will:
1. Appear as a blue chat bubble (with a music/chat icon) in the bottom-right corner.
2. Show a welcome message and interactive quick-reply buttons when users click it.
3. Answer questions about courses, registration, the founder, and fees.
4. Close when users click the X button.

**To test it:**
1. Open any page of your website in a browser.
2. Click the chat bubble in the bottom-right corner.
3. Select any quick-reply button (e.g., "Courses Offered", "How to Enroll", "Studio Recording").
4. Or type custom questions like:
   - "Tell me about Dominic Ansah Asare"
   - "How much is piano registration?"
   - "Where are you located in Accra?"
   - "What are your hours?"

## 🛠️ Customization Options

### 1. **Change the Chatbot Color**

Edit `assets/css/chatbot.css` and replace the brand colors with your preferred accents.

### 2. **Update the Knowledge Base**

Edit `assets/js/chatbot.js` to add more information about your courses, events, or workshops.

**Modify existing responses:**
Find the topic in the `KnowledgeBase` object and update the `response` field with your custom text.

---

## 🐛 Troubleshooting

### **Chatbot not appearing?**
- Check if `chatbot.css` and `chatbot.js` are in the correct directories
- Verify the script tags are correctly added to all HTML files
- Check browser console (F12) for JavaScript errors

### **Answers not appearing?**
- Make sure keywords in the knowledge base match user questions
- Check the browser console for errors
- Verify JavaScript is enabled in your browser
